# Expense Tracker

## Description
A console-based Java application to manage daily expenses.

## Features
- Add Expense
- View Expenses
- Search Expense by ID
- Search Expenses by Category
- Update Expense
- Delete Expense
- Calculate Total Expense
- Save Expenses to File

## Technologies Used
- Java
- Eclipse IDE
- Object-Oriented Programming
- ArrayList
- File Handling

## Concepts Used
- Classes and Objects
- Constructors
- Methods
- Loops
- Conditional Statements
- ArrayList
- FileWriter
- Exception Handling

## Future Improvements
- MySQL Database using JDBC
- Login System
- Monthly Reports
- GUI using JavaFX
